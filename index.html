ViralClip

Aplicativo pessoal de computador (Windows) usado pelo dono do canal Klipou para criar e publicar os próprios cortes.

O que ele faz

  • Transforma vídeos longos em cortes curtos verticais, com legendas, no próprio computador.
  • Organiza um calendário de publicação.
  • Envia e agenda os cortes no canal do YouTube do próprio dono, pela API oficial do YouTube (YouTube Data API v3).

Quem usa

Só o dono do aplicativo, nas próprias contas. O ViralClip não é vendido nem oferecido como serviço a outras pessoas, e não tem servidor: tudo roda no computador do dono.
