Política de Privacidade — ViralClip

Última atualização: 10 de outubro de 2026 (página Desempenho)

O ViralClip é um aplicativo pessoal de computador (Windows), usado somente pelo seu dono para criar cortes de vídeo e publicá-los nas próprias contas. Ele não tem servidor próprio: todos os dados ficam no computador onde o aplicativo está instalado.

1. Quais dados do Google/YouTube o aplicativo acessa

Quando o dono conecta a conta do Google, o ViralClip pede apenas estas permissões da YouTube Data API v3:

  • youtube.upload — para enviar os vídeos criados pelo próprio aplicativo ao canal;
  • youtube.force-ssl — para agendar a publicação, alterar o título, a descrição e o horário desses vídeos, consultar se foram processados e publicados, ler o nome do canal conectado, as estatísticas públicas (visualizações, curtidas, número de comentários) dos vídeos publicados pelo aplicativo e, somente se o dono ativar na página Desempenho, os comentários desses vídeos (texto, nome público do autor, data e curtidas), para ele acompanhar e responder pelo YouTube Studio;
  • yt-analytics.readonly (opcional) — para ler os relatórios do YouTube Analytics do próprio canal (visualizações por dia, tempo assistido, compartilhamentos e duração média assistida) e mostrar o desempenho dos vídeos na página Desempenho. Quem não marcar essa permissão continua usando o aplicativo normalmente.

O aplicativo usa essas permissões somente para essas funções. Ele não lê mensagens, inscritos nem dados de outros canais, não responde comentários sozinho e não acessa informação além do necessário para publicar e acompanhar os vídeos do próprio dono.

2. Onde os dados ficam

  • As credenciais de acesso (token de atualização e a chave do cliente OAuth) ficam somente no computador do dono, criptografadas com a proteção de dados do Windows (DPAPI). O token de acesso temporário fica apenas na memória enquanto o aplicativo está aberto.
  • Título, descrição, horário e o identificador dos vídeos publicados, as métricas lidas (com o histórico usado para calcular crescimento) e, se ativados, os comentários ficam no banco de dados local do aplicativo, no mesmo computador. Métricas antigas são agregadas automaticamente e os comentários têm limite de armazenamento.
  • Nenhuma credencial é gravada em registros (logs), arquivos de texto ou exibida na tela.

3. Compartilhamento

Os dados do Google/YouTube não são vendidos, compartilhados nem transferidos a terceiros, e não são usados para publicidade ou para treinar modelos de inteligência artificial. Os vídeos vão do computador do dono diretamente para a API oficial do YouTube.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Serviços do YouTube

O ViralClip usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. A Política de Privacidade do Google também se aplica aos dados tratados pelo YouTube.

5. Como revogar o acesso e apagar os dados

  • No aplicativo: Publicação → Configurar → YouTube → Desconectar. Isso revoga o acesso no Google e apaga as credenciais do computador.
  • A qualquer momento, também pelo Google: myaccount.google.com/connections ou página de permissões de segurança.
  • Desinstalar o aplicativo e apagar a pasta dele remove todos os dados locais.

6. Outras plataformas

Para o TikTok, o aplicativo usa o serviço Buffer, com a conta do próprio dono. Os vídeos enviados ao TikTok passam pelo Buffer conforme a política de privacidade desse serviço, e as métricas dos posts do TikTok (visualizações, curtidas, comentários, compartilhamentos e tempo assistido) são lidas da API do Buffer. Nenhum dado do Google/YouTube é enviado ao Buffer.
